# DotaWardMap v9

Открытый инструмент для анализа вардов Dota 2 на Python и Streamlit. Вставьте Steam-профиль или Steam32/Steam64, выберите число последних матчей и нажмите «Смотреть профиль». Карта Observer/Sentry загружается через агрегированный endpoint OpenDota wardmap, как в v5. Выбора отдельных матчей нет. Одинаковые места постановки объединяются, размер точки зависит от количества постановок.

Карта **7.39** находится в `assets/map_7_39.png` и загружается локально, без обращения к сайту с картинками. Фон фиксированный: ландшафт матчей других патчей может отличаться. Выделите область левой кнопкой мыши для приближения, дважды щёлкните для сброса. Колесо прокручивает страницу и не масштабирует карту.

## Windows: запуск с нуля

1. Установите Python 3.12 или 3.13 с https://www.python.org/downloads/windows/ и включите **Add python.exe to PATH**. Откройте новое окно PowerShell.
2. Скачайте проект (GitHub → Code → Download ZIP), распакуйте ZIP.
3. Откройте папку, где лежат **app.py и requirements.txt**, и запустите там PowerShell. Если после распаковки появилась вложенная папка, зайдите в неё.
4. Вставьте команды по очереди:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Активация окружения и изменение ExecutionPolicy не нужны. Откройте http://localhost:8501 . Окно PowerShell оставьте открытым, для завершения нажмите Ctrl+C. Для повторного запуска достаточно последней команды; также можно дважды нажать `run_windows.bat`.

## Linux / macOS

Установите Python 3.12/3.13. В Ubuntu/Debian при необходимости установите пакет python3-venv. В папке с app.py:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

Это локальное веб-приложение: интерфейс открывается в браузере. Для данных OpenDota необходим интернет. Dota 2 и Steam устанавливать не требуется.

## Как пользоваться

Вставьте ID (например `1324728778`), полный Steam URL `/profiles/…`, `/id/…` или OpenDota URL `/players/…`. Установите «Матчей учитывать» (по умолчанию 100, максимум 1000), нажмите «Смотреть профиль». Затем настройте отображение Observer/Sentry и размер точек. После изменения числа матчей нажмите кнопку снова. CSV содержит агрегированные координаты и количество постановок; PNG готовится отдельной кнопкой.

Если данных нет, попробуйте увеличить число матчей и обновить историю. Обновление истории OpenDota асинхронное и не гарантирует разбор реплея; наличие матча не гарантирует наличие координат вардов. Поиск Steam custom URL не подменяется поиском по нику: если Steam не отдаёт ID, используйте числовой ID.
