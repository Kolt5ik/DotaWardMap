# Визуальные материалы документации

- **cover.svg** — графическая обложка: типографика, сетка координат и схематичные маркеры Observer/Sentry. Создана в SVG без генерации растровой иллюстрации; не изображает точную карту игры или статистику игрока.
- **banner.svg** — лёгкая абстрактная альтернативная обложка в SVG.
- **preview.gif** — анимированный обзор двух предоставленных скриншотов. Показывает два состояния интерфейса; не является записью взаимодействия мышью. Сформирован как анимация средствами FFmpeg, исходные скриншоты сохранены.
- **download-windows.svg**, **download-windows-en.svg** — кнопки-ссылки для README. Ссылки ведут на настоящий EXE последнего релиза.
- **heatmap.png** и **points-overlay.png** — предоставленные автором скриншоты проверки настоящего интерфейса v9.0.4. Не обещают полноту показанной статистики.

Игровая подложка и игровые материалы © Valve. Источник карты и её обработка: [assets/README.md](../../assets/README.md). Код и текст проекта распространяются по MIT, что не изменяет права на игровые материалы.

В автономное демо встроен Plotly.js, распространяемый по MIT; уведомление о лицензии присутствует в его исходном коде. Учебный набор находится в docs/demo-data.json. Демонстрация не обращается к внешним сайтам.
