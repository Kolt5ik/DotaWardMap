# Решение проблем

[← Главная](../README.md) · [Установка](installation.md)

## Карта пустая или вардов слишком мало

OpenDota может не иметь данных разбора реплеев за выбранные матчи.

1. Проверь, что выбран нужный профиль.
2. Увеличь лимит матчей и нажми «Смотреть профиль».
3. Нажми «Обновить историю OpenDota», подожди и позже загрузи профиль снова.
4. Учитывай предупреждение о неполной статистике.

Это не гарантирует появления данных. Приложение не может восстановить отсутствующие координаты из агрегированного endpoint.

## Не определяется custom Steam URL

Вставь полный адрес `https://steamcommunity.com/id/…/`. Отображаемый ник сам по себе не подходит.

Если Steam не отдаёт XML/HTML профиля, попробуй `/profiles/<SteamID64>/`, числовой SteamID64, account ID или ссылку OpenDota. Не выбирай случайный результат поиска по похожему нику.

## Ошибка HTTP / OpenDota недоступен

Проверь интернет. При HTTP 429 сократи частоту запросов и повтори позже. При серверных ошибках OpenDota попробуй позже. Сохрани полный текст ошибки для issue; повторный запуск приложения не гарантирует исправления внешнего сервиса.

## EXE скачан, но интерфейс не появился

Дождись завершения старта, затем открой [http://127.0.0.1:8501](http://127.0.0.1:8501) вручную. Если сервер не доступен, проверь, запустился ли процесс, и собери текст ошибки или системного уведомления.

Если файл скачан из Actions, сначала распакуй ZIP. Используй файл из нужного запуска сборки; старый релиз не содержит изменений ещё не опубликованной ветки.

## Новая версия выглядит как старая

Старый EXE может ещё обслуживать адрес 8501.

1. В старом приложении нажми «Завершить приложение».
2. Закрой старую вкладку.
3. Запусти новый EXE из отдельной папки.
4. Открой свежую вкладку и проверь новый режим.

Если интерфейс старого процесса недоступен, заверши именно **DotaWardMap.exe** через Диспетчер задач. Не завершай все процессы Python.

## Закрыл вкладку, а приложение осталось работать

Для EXE используй **«Завершить приложение»**. Закрытие вкладки не останавливает локальный сервер.

Для исходников нажми **Ctrl+C** в терминале, который запускал Streamlit. Кнопка завершения EXE в этом режиме не отображается.

## Не работают команды Python или Streamlit

Если `python` не найден, установи Python с добавлением в PATH и открой новый PowerShell.

Если не найден `streamlit`, используй команду через созданное окружение:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address=127.0.0.1 --browser.gatherUsageStats=false
```

Если нет `.venv`, сначала пройди [установку](installation.md). При отсутствии `requirements.txt` проверь текущую папку: нужен корень распакованного проекта.

## Git пишет «not a git repository»

Перейди в папку своего клонированного проекта. Установка из ZIP не содержит Git-историю; для работы с ветками используй `git clone`.

## Нет Artifacts или новой версии в Releases

Тестовые сборки ветки находятся в **Actions**, а релизы — в **Releases**.

Открой конкретный успешно завершённый запуск по названию. Прокрути его страницу к **Artifacts**. Если сборка упала, проверь красный шаг в job. Если artifact истёк или удалён, запусти workflow заново.

Для релиза требуется тег `v*` и успешная сборка. Создание ветки или pull request само по себе релиз не публикует.

## PNG не экспортируется

Экспорт зависит от совместимости Plotly и Kaleido. В текущих зависимостях закреплён Kaleido 0.2.1, а версия Plotly имеет диапазон: работа PNG не гарантирована для всех разрешённых сочетаний.

Сохрани CSV или сделай снимок экрана. В issue укажи способ запуска, версию приложения и, если работаешь с исходниками, версии зависимостей. Не меняй версии наугад перед сохранением сведений об ошибке.

## Позиции кажутся смещёнными

Подложка фиксирована на 7.39. Для других патчей ландшафт может отличаться; полная проверка привязки всех объектов не выполнена. В отчёте укажи патч, область карты и пример координат.

## Сообщить об ошибке

[Создай issue по шаблону](https://github.com/Kolt5ik/DotaWardMap/issues/new/choose). Укажи версию, ОС, способ запуска, шаги воспроизведения, ожидаемый результат и точный текст ошибки. Скриншот полезен; убери приватные данные.
