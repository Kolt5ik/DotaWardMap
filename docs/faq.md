# Частые вопросы

[← Главная](../README.md) · [Проблемы запуска](troubleshooting.md)

## Это сайт или приложение?

Локальное приложение с интерфейсом в браузере. EXE запускает сервер на твоём компьютере; браузер показывает страницу по адресу 127.0.0.1:8501. Публичного сервера проекта для загрузки профилей сейчас нет.

## Нужна ли установленная Dota 2?

Нет. Данные запрашиваются у OpenDota. Для custom Steam URL приложение дополнительно определяет ID через Steam Community.

## Нужно входить в Steam или вводить API key?

Нет. Текущая реализация работает без входа в Steam и пользовательского ключа API. Это не означает, что внешний сервис всегда доступен или всегда имеет нужные данные.

## Можно посмотреть другого игрока?

Да, если OpenDota предоставляет данные его профиля и координаты. Закрытые или отсутствующие данные приложение не восстанавливает.

## Почему одинаковые места объединены?

Wardmap уже содержит агрегированные координаты и количества. Один маркер может обозначать много установок. Точное число доступно при наведении и в поле count CSV.

## Почему изменил число матчей, а карта та же?

Нажми «Смотреть профиль» снова. Если результат всё равно похож, за дополнительными матчами могут отсутствовать разобранные данные, либо распределение действительно изменилось мало. GET-ответы кешируются на две минуты.

## Что означает красное пятно?

Высокую плотность установок выбранного типа относительно других мест текущей карты. Это не оценка качества позиции и не индикатор обзора.

## Можно сравнивать красный цвет у двух игроков?

По цвету нельзя сравнить абсолютное количество: каждый результат нормализуется отдельно. Для количественного сравнения нужны count и показатели, с учётом неполноты данных.

## Почему в тепловом режиме всё ещё видны оба типа точек?

Переключатель «Плотность для» задаёт тип теплового слоя. «Показать точки поверх» добавляет оба типа маркеров. Это разные слои.

## CSV учитывает выбранные фильтры?

Нет, он содержит весь загруженный набор обоих типов. Фильтры меняют отображение карты.

## Можно выбрать конкретные матчи, героя или дату?

В текущей версии таких фильтров нет. Доступен агрегированный запрос последних N матчей. В CSV нет времени установки или ID каждой игры.

## Почему карта не соответствует новому патчу?

Используется фиксированная подложка 7.39. Замена изображения требует проверки координат и происхождения материала; сама загрузка нового изображения не гарантирует корректную привязку.

## Можно сохранить приближённый участок PNG?

Приближение в браузере не передаётся в серверный экспорт. Для выбранного участка используй снимок экрана. PNG сохраняет карту с выбранными слоями.

## Можно ли использовать без интернета?

Реальные профили требуют доступа к OpenDota. Для знакомства есть отдельное [офлайн-демо](demo.md) на учебных данных.

## Как поддержать проект?

Сообщи об ошибке с понятными шагами, улучши перевод, предложи проверенное изменение или поделись ссылкой. Правила участия — в [CONTRIBUTING.md](../CONTRIBUTING.md).
