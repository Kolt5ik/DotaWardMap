# Руководство пользователя

[← Главная](../README.md) · [Установка](installation.md) · [Решение проблем](troubleshooting.md)

## Первый разбор

1. Запусти приложение.
2. В поле **Steam / OpenDota / account ID** вставь ссылку или числовой ID.
3. Выбери **«Матчей учитывать»** — от 1 до 1000, по умолчанию 100.
4. Нажми **«Смотреть профиль»** и дождись загрузки.
5. Выбери режим точек или тепловую карту.

После изменения числа матчей нажми «Смотреть профиль» ещё раз. Переключение типа вардов и режима карты использует уже загруженные данные.

## Какие профили принимаются

| Формат | Пример формы ввода |
| --- | --- |
| Steam custom URL | `https://steamcommunity.com/id/your-custom-url/` |
| Steam профиль по ID | `https://steamcommunity.com/profiles/<SteamID64>/` |
| OpenDota | `https://www.opendota.com/players/<account_id>` |
| SteamID64 | Числовой 17-значный ID профиля |
| Steam32 / account ID | Числовой ID аккаунта, используемый OpenDota |

В примерах с угловыми скобками подставь свой ID. Обычный отображаемый ник Steam не является уникальным идентификатором. Используй ссылку профиля.

## Режим точек

Сними галочку **«Тепловой слой»**.

- **Observer:** жёлтые круги.
- **Sentry:** голубые квадраты.
- Галочки типов скрывают или показывают соответствующие маркеры.
- **«Размер точек»** меняет общий масштаб маркеров.
- **«Непрозрачность точек»** помогает рассмотреть карту под ними.

Установки в одной координате объединены. Размер маркера пропорционален квадратному корню из количества постановок. Наведи курсор, чтобы увидеть тип, координаты и точное число.

## Тепловая карта

Включи **«Тепловой слой»**, затем выбери **Observer** или **Sentry**.

Плавные пятна объединяют соседние позиции с учётом числа установок. Жёлтые, оранжевые и красные участки показывают рост относительной плотности. В области с низкой плотностью слой становится прозрачным.

**«Показать точки поверх»** добавляет маркеры **обоих типов**. Выбранный переключатель Observer/Sentry относится к плотности, а не к этому точечному слою.

Ширина пятен и шкала интенсивности задаются автоматически. Пользовательских ползунков для них нет. Цвет нельзя напрямую сравнивать между разными профилями или запросами: шкала нормализуется отдельно. Слой не показывает радиус обзора.

## Приближение карты

Зажми левую кнопку мыши и выдели прямоугольник. Дважды щёлкни, чтобы сбросить приближение. Колесо прокручивает страницу и не увеличивает карту.

Фон всегда соответствует патчу **7.39**. Участки ландшафта в более ранних или поздних матчах могут отличаться.

## Показатели и таблица

Показатели Observer/Sentry/Всего — суммы полученного поля `count`. Они относятся ко всему загруженному набору и не меняются от скрытия маркеров.

В **«Данные вардов»** доступны столбцы `type`, `x`, `y`, `count`. Одна строка — агрегированная позиция определённого типа, а не обязательно одна установка. [Как формируются данные](data.md).

## Экспорт

**CSV:** нажми «Скачать данные CSV». Файл содержит оба типа вардов из загруженного набора, даже если один скрыт на карте. Координаты сохраняются в сетке OpenDota.

**PNG:** нажми «Подготовить PNG карты», затем «Скачать карту PNG». Экспортируется карта с выбранными слоями. Приближение мышью в браузере не передаётся в серверный экспорт; для сохранения приближённого участка используй снимок экрана. Если подготовка PNG не удалась, используй CSV.

## Обновление истории

Нажми **«Обновить историю OpenDota»**. Приложение отправит запрос обновления и очистит кеш API. Обновление выполняется асинхронно: позже снова нажми «Смотреть профиль».

Кнопка не гарантирует разбор реплеев. Например, пять полученных вардов при лимите десять матчей могут означать неполные данные. Приложение не знает точного покрытия этих десяти матчей.

## Завершение работы

В **EXE** нажми «Завершить приложение» и дождись сообщения. Локальный сервер остановится, вкладку можно закрыть.

При запуске **из исходников** нажми **Ctrl+C** в терминале. Кнопка завершения EXE в этом режиме скрыта.
